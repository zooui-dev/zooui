ZOptionalDate: unticking the box disables and greys out the date but leaves it in v-model, and a day the parent sets no longer ticks the box; the new clear-when-off prop brings back the old behavior, where the model is null while the box is off and the day comes back on a tick. Nothing is written at mount in either mode, so a box bound off with a day in hand no longer clears the day and marks a loaded form as changed, and an enabled bound to undefined stays undefined until the user toggles. A new @enabled-change event fires with the new state when the user ticks or unticks the box, never when the parent sets it or the day: the moment to fetch a default date. It now reads its size from a surrounding UFieldGroup, which it skipped before: an explicit size prop still wins, then the UFieldGroup, then the UFormField, as Nuxt UI's own inputs read it. ZDateField: the shortcut keys step from the committed date (or today), not from text typed since, so with 03/15/2026 saved, typing 04/0 then + gives 03/16/2026; eight digits are read as month, day and year (05122026), in each format's own order; and a #leading slot takes the place of the icon.
