ZSelectMenu is Nuxt UI's USelectMenu with the keyboard of a data-entry form, and every USelectMenu prop, slot, event and v-model passes through unchanged. Typing on the closed menu picks the first matching item, as in a native select, and announces it; Tab closes the open menu and moves to the next field, taking the highlighted item in a single-select menu with a search input once you have typed or moved the highlight, and leaving the value as it was otherwise; the menu opens on the selected item; and open-on-focus opens it on keyboard focus, for fast data entry. Each is a prop that can be switched off.
