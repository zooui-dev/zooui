Read readme.md in this skill, then open index.html to see every component at real size.
Link styles.css (or import tailwind.css after tailwindcss) and build with the ui-* classes or the utility recipes in RECIPES.md. Never hard-code a hex, font name or spacing value the tokens already carry.
If creating visual artifacts (slides, mocks, throwaway prototypes), copy the assets out and write static HTML. If working on production code, read the rules here and lift the values.
If invoked with no other guidance, ask what to build, ask a few questions, and act as an expert designer who outputs HTML artifacts or production code.
