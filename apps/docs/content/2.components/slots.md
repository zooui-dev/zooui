title: Slots
description: Capacity as one named chip per slot, open or held, as a labeled list.
component: ZSlots
preview: SlotsCapacity
---

Blank colored bars read as empty tags, so each slot of capacity is a chip that says what it is: an open slot is a solid primary badge, a held one an outline badge naming what holds it. `title` adds a tooltip, and `label` names the whole list for assistive technology.
