title: Identifier
description: A value set in the mono face — a package name, a version, a hash — on a chip.
component: ZIdentifier
preview: IdentifierKinds
---

Values a reader copies or compares — package names, versions, commit hashes, service names — read best in the mono face. `ZIdentifier` sets its slot that way, on a chip, except for `plain`. A `version` is set in the accent.
