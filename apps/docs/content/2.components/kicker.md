---
title: Kicker
description: The mono label over a section, bracketed in the primary or set as an eyebrow.
component: ZKicker
preview: KickerBracket
---

A kicker names the section below it in the mono face, uppercase and tracked. The default `bracket` variant wraps the label in brackets in the primary color.

::component-example{name="KickerBracket"}
::

## Eyebrow

`variant="eyebrow"` is a label with no brackets, the label itself in the accent ink. Pair it with a heading that sets one word in the accent.

::component-example{name="KickerEyebrow"}
::
