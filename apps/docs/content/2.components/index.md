Zoo UI adds components only where Nuxt UI has no equivalent. For everything else, use Nuxt UI's own: `UAlert variant="outline"` is Forest's banner, `UTable` its table and `UTabs` its segmented control. All of these are prefixed `Z` and come with `@zooui/nuxt`, so they work on the theme-free base too.
